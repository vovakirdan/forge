## Canonical knowledge and memory

Human/authorized Manager authors/publishes/supersedes/withdraws versioned Markdown
knowledge (introduction, architecture, guide, policy, decision). Employee proposes
Artifact/observation. Summarizer only creates derived TaskSummary, personal
EmployeeMemoryEntry and ProjectKnowledgeEntry. It never accepts authority,
Artifacts or Task/Pipeline transitions or semantically verifies a reported claim.

PostgreSQL owns bounded content/scope/visibility/revision/hash/source refs/coverage/
history. Attachments use existing Artifacts/object storage. Source existence,
scope and permissions are checked; private inputs cannot become public output.
Core supplies canonical actors/timestamps/sequences. Exact replay deduplicates,
conflicting assertions keep attribution until explicit authorized decision.

## SystemJob

Kinds: Summarization, Onboarding. Owner is exact job attempt, not contextual Task
or target Employee. Ownerless Run/Lease/reservation retain generation/fence/epoch.
Existing controlled provider egress gets a strict SystemJob scope branch; no
authentication bypass or Task tools. Surface is None, runtime has private scratch.
Separate semantic concurrency defaults to one per Project; existing host/project/
account caps still apply. No Employee capacity slot. Explicit attempt/time/input/
output quotas; missing usage is unknown rather than zero.

Stop blocks new dispatch and stops active inference but preserves pending jobs
and coverage. Stopped/stale output remains evidence, not current memory.
Canonical ingestion/outbox/index/visibility updates without LLM may continue.
After restart retry only follows confirmed physical quiescence. Persisted completed
result is accepted idempotently without repeated inference.

## Summarizer

Significant events via outbox coalesce durable source ranges; heartbeat/tool-call
volume never maps one-to-one to model calls. Bounded immutable snapshots use Task,
Handoff, Artifacts, outcomes; technical excerpts require explicit selection,
redaction and bounds. Late evidence can expand coverage. Schema/source/visibility
checks required; exit zero is not accepted result. Own output/index/job events
cannot recurse. Summarization failure/budget never blocks handoff or Pipeline.
Backfill of M0–M2 is explicit, scoped and bounded, never automatic.

## Retrieval/context/onboarding

Required applicable published Policies and accepted Decisions are read directly
from Core, independent of search/top-k. Required context overflow causes a clear
preflight refusal, not silent omission. Search outage falls back to Task/Handoff/
Artifacts and authority. Core revalidates current revision/visibility/sources
before canonical text is frozen into BOTH actual provider prompt and ContextSnapshot.
Explicit refresh creates a new auditable snapshot, never edits an existing one.

Onboarding pins introduction, architecture, current goal if defined, role,
responsibilities, prompt versions, tools/capabilities and authority. Result is a
persistent personal note plus receipt/familiarity versions, not comprehension or
provider-session proof. New Employee is gated until completion or explicit Manager
skip; retry is explicit. Existing Employees get legacy bypass, not false completion.
Page edits do not automatically rerun onboarding for everyone.

## AgentMemory projection compatibility

Use dedicated worktree/branch, container/home/volume and service credentials.
Never touch personal AgentMemory daemon/config/data. Local embeddings and pinned
model/dependencies; disable LLM keys and automatic forgetting/consolidation/
compression/reflection/injection. Prove real embed/search, not only livez.

BM25 add removes previous ID postings/statistics. Existing import supports optional
strictIndexing:true with merge only; legacy behavior unchanged. Strict success
requires storage:complete plus indexing.version=1, mode=strict, expected equal to
bm25Indexed and vectorIndexed and request count, persisted=true.
Old/missing/partial ack is not readiness. Missing prerequisites reject before writes.
Partial index/save failure reports retryable failure without claiming KV rollback.
All index saves serialize snapshots inside one queue; strict save propagates errors.

Each immutable canonical entry/revision/hash maps to one persisted projection UUIDv7.
Retries reuse ID/payload; new revision has new ID. Old completion cannot replace
latest mapping. AgentMemory text is untrusted: Core rehydrates canonical content
after scope/revision/source checks. Withdrawal excludes reads immediately even if
remote deletion lags. Rebuild uses Forge sources, never personal memory.
